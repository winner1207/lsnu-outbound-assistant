# 过程进度显示增强设计

## 目标

在图片识别和七语生成等待期间，持续向用户展示可验证的阶段动作，降低长时间等待的不确定感。

## 方案

沿用现有 SSE 流程，在图片压缩、OCR、术语匹配、视觉识别、检索、术语表准备、语言生成和锁词等耗时节点发送 `status` 事件。事件只描述程序正在执行的公开阶段，不展示模型原始 thinking 或隐藏推理内容。

前端沿用处理记录区域，记录每条状态的时间，并显示当前阶段的动态等待时长。等待持续时使用友好提示，收到识别、部分生成、完成或错误事件后停止对应状态。

## 兼容性与验证

不改变现有 API 响应结构和会话逻辑，仅增加 SSE 状态事件与前端展示逻辑。通过现有 Python 测试，并增加后端事件顺序测试，确保完整流程仍能完成。
