# 跨地域识图与生成链路修复记录

## 修复范围

- 初判不注入地域词库或景点排除名单，按画面生成候选，不调用搜索、不启用深度思考。
- 使用当前 Token Plan 的 Responses API，web_search + tool_choice=required；验证服务端 web_search_call 与 sources，拒绝无调用记录的记忆回答。
- 核验同时接收图片与初判；来源取服务端返回值与模型引用的交集，核验后地点更新到页面、会话和讲解。
- 删除图片链路中的硬编码瀑布搜索与四次串行 Wikipedia 请求。
- 中文先交付；其它六语忠实翻译中文，最多三个并发，各自失败互不阻断。明确失败状态，不将空结果、截断结果当完成。
- 仅传入相关译名，移除单语生成时的七语 JSON 提示冲突。
- 处理记录转义、序号留白、阶段等待计时、来源链接、新请求清理旧会话和断流检测一起修复。

## 验证

- 45 个 Python 测试通过；JavaScript 语法检查通过。
- 新增回归覆盖：地域隔离、真实搜索调用、来源过滤、核验更新会话、搜索失败降级、中文先交付、翻译沿用中文、单语失败隔离、流截断识别。
- 真实本地浏览器 14.jpg：峰林布依景区；核验54.9秒，中文56.8秒，七语63.5秒；多位序号完整可见，来源可点击。
- 真实本地链路 13.jpg：安顺龙宫龙门飞瀑；中文91.7秒，七语98.7秒。
- 测量值为单次真实调用，不作为速度承诺。搜索来源存在不等于事实绝对正确；模型核验仍可能误判，需要持续跨地域样本验证。

## 发布检查

发布前备份相关远程文件，核对模型配置（不输出密钥）。上传后检查语法、重启应用、检查健康接口与公网真实SSE流程。

首轮公网测试发现搜索超过90秒预算，降级为待核验候选但七语仍完整交付。随后限制最多两次搜索、缩短核验资料与输出，本地同图核验30.2秒返回正确地点和来源。使用 `scripts/check_photo.py URL IMAGE --expected 地点关键词 --report debug/report.json` 验证真实上传、来源、七语与done事件；失败不会被健康检查掩盖。
